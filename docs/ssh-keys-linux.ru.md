# Создание SSH-ключа в Linux

[English version](ssh-keys-linux.md) · [Настройка через консоль провайдера](bootstrap-console.ru.md)

Выполняйте команды в терминале **на своём компьютере**, не в консоли VPS. Если вы запускаете репозиторий из Windows Subsystem for Linux (WSL), откройте терминал WSL и используйте эти же команды.

1. Создайте каталог `.ssh` и новую пару ключей Ed25519:

   ```sh
   mkdir -p "$HOME/.ssh"
   chmod 700 "$HOME/.ssh"
   ssh-keygen -t ed25519 -a 100 -f "$HOME/.ssh/standalone_3x_ui_ed25519"
   ```

   Придумайте парольную фразу, введите её и подтвердите. Если файл уже существует, **не перезаписывайте его**: выберите другое имя и укажите полный путь к нему в `.env` через `SSH_KEY_PATH`.

2. Покажите публичный ключ:

   ```sh
   cat "$HOME/.ssh/standalone_3x_ui_ed25519.pub"
   ```

   Скопируйте **всю одну строку**, начинающуюся с `ssh-ed25519`: её нужно поместить на VPS в `authorized_keys`. Файл без `.pub` — приватный ключ. Он остаётся на вашем компьютере; его нельзя вставлять в консоль провайдера или репозиторий.

3. Перед запуском установщика добавьте ключ с парольной фразой в SSH-агент:

   ```sh
   eval "$(ssh-agent -s)"
   ssh-add "$HOME/.ssh/standalone_3x_ui_ed25519"
   ```

   Введите парольную фразу на своём компьютере. При таком имени файла оставьте в `.env` строку `SSH_KEY_PATH=~/.ssh/standalone_3x_ui_ed25519`. Установщик проверяет SSH без интерактивного запроса, поэтому защищённый ключ должен быть доступен через агент.

Продолжайте по [инструкции для консоли провайдера](bootstrap-console.ru.md). Если провайдер разрешает SSH-вход `root` по паролю, публичный ключ может установить автоматическая настройка из [README](../README.ru.md).

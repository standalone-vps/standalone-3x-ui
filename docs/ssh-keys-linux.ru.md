# SSH-ключ в Linux

[English version](ssh-keys-linux.md)

Выполняйте команды **на компьютере с Linux**. Приватный ключ остаётся там. Публичный ключ имеет окончание `.pub`.

```text
Создать ключ → скопировать публичную строку → добавить приватный ключ в SSH-агент
```

1. Создайте ключ:

   ```sh
   mkdir -p "$HOME/.ssh"
   chmod 700 "$HOME/.ssh"
   ssh-keygen -t ed25519 -a 100 -f "$HOME/.ssh/standalone_3x_ui_ed25519"
   ```

   Придумайте парольную фразу и повторите её. Если файл уже существует, ответьте **no**. Используйте его, только если это ваш ключ и рядом есть файл `.pub`. Иначе замените имя во всех следующих командах и в `.env`.

2. Покажите публичный ключ:

   ```sh
   cat "$HOME/.ssh/standalone_3x_ui_ed25519.pub"
   ```

   Скопируйте **всю одну строку** в `/home/ops/.ssh/authorized_keys` на VPS. Приватный файл туда не переносите.

3. Подготовьте приватный ключ для установщика:

   ```sh
   eval "$(ssh-agent -s)"
   ssh-add "$HOME/.ssh/standalone_3x_ui_ed25519"
   ```

   Введите парольную фразу на своём компьютере. Для этого имени файла задайте в `.env` `SSH_KEY_PATH=~/.ssh/standalone_3x_ui_ed25519`.

Полная установка VPS описана в одном [основном руководстве](../README.ru.md).

# Security policy

[Читать по-русски](SECURITY.ru.md)

## Supported code

Only the current `main` branch is maintained. The pinned 3x-ui release is a dependency; follow its upstream security notices as well.

## Report a vulnerability

1. Open the repository's **Security and quality** tab and select **Report a vulnerability** if that button is available. This sends a private report to the maintainers.
2. If the button is unavailable, open a public issue asking the maintainers for a private contact method. Do **not** put vulnerability details in that issue.
3. Do not publish a proof of concept, credentials, IP addresses, domains, client links, or subscription URLs before the maintainers have a chance to review the report.

For ordinary bugs and setup questions, use a regular issue with sanitized output. Never paste the real `.env` or `/etc/x-ui/install-result.env`.

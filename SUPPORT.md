# Support

[Читать по-русски](SUPPORT.ru.md)

Start with the [setup guide](README.md). If a command fails, open an [issue](https://github.com/standalone-vps/standalone-3x-ui/issues/new/choose). Name the step, your local OS, the VPS Ubuntu version, and the sanitized error. Do not include real addresses, keys, passwords, tokens, client links, or `.env`.

For a vulnerability, use [private reporting](SECURITY.md). This community project does not provide an emergency response or managed VPS support.

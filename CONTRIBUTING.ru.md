# Как помочь проекту

[English version](CONTRIBUTING.md)

Этот проект устанавливает сетевые службы на VPS. Делайте небольшие изменения, которые легко проверить.

1. Создайте issue для ошибки или предложения. Не публикуйте реальный IP-адрес, домен, SSH-ключ, пароль, данные панели, токен, ссылку клиента, адрес подписки или файл `.env`.
2. Сделайте изменение в отдельной ветке. Если меняете шаг для пользователя, обновите инструкции на английском и русском языках.
3. Запустите проверки ниже. Они не подключаются к VPS.
4. Создайте pull request. Опишите изменение, проверки и влияние на SSH, фаервол, сертификаты или данные 3x-ui.

```sh
python3 -m pip install 'pytest>=8,<9'
python3 -m pytest -q
python3 -m compileall -q bin
```

Не проверяйте pull request командой `deploy --apply` на чужом VPS. Не добавляйте в Git рабочий `.env`, учётные данные, резервные копии и выгрузки. Об уязвимости сообщите по инструкции [SECURITY.md](SECURITY.ru.md).

Изменение закреплённой версии 3x-ui требует отдельной проверки выпуска и установки. Укажите точную версию и результат проверки в pull request.

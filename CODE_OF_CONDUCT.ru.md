# Правила общения

[English version](CODE_OF_CONDUCT.md)

Общайтесь уважительно в issue, pull request и обсуждениях. Обсуждайте работу, а не личность или способности человека. Не допускайте травли, угроз, раскрытия личных данных и оскорблений по признакам личности.

Сопровождающие могут удалить вредные сообщения и ограничить участие. Чтобы сообщить о нарушении, нажмите **Report content** у соответствующего сообщения на GitHub. Не публикуйте чужие личные данные. Об уязвимостях программного обеспечения сообщайте по инструкции [SECURITY.md](SECURITY.ru.md).

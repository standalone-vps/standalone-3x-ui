# Code of conduct

[Читать по-русски](CODE_OF_CONDUCT.ru.md)

Be respectful and constructive in issues, pull requests, and reviews. Discuss the work, not a person's identity or abilities. Do not harass, threaten, disclose private information, or post hateful content.

Maintainers may edit or remove harmful content and restrict participation. Use GitHub's **Report content** control on the relevant comment to report abuse. Do not publish another person's private information in a report. For software vulnerabilities, use [SECURITY.md](SECURITY.md).
